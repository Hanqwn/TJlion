# Lion Manager 原生应用使用说明

Lion Manager 使用 Flutter/Dart 构建为原生应用。Windows 版在自己的应用窗口运行；Android 版以 APK 安装，不使用浏览器或 WebView。

## 下载与安装

- **Windows**：从 [GitHub Releases](https://github.com/Hanqwn/TJlion/releases) 下载并解压完整 Windows ZIP，运行 `dist/native/windows/lion_team_manager.exe`。请保留旁边的 DLL 和 `data/` 目录。
- **Android**：从 GitHub Releases 下载 APK 并侧载安装。APK 使用项目 debug key 签名，适合内部侧载；不用于 Play Store 发布。
- 本次发布仅提供 Windows 和 Android 包；Linux、macOS、iOS 目录是源码，不代表已有安装包。

## 首次启动与数据库

安装包不含预置成员数据或 `seed.sqlite3`。首次启动会根据 `assets/schema.sql` 创建空的本机数据库。已有用户可在 **设置 → 导入数据库** 中选择要继续使用的 SQLite 文件。数据库是普通 SQLite，不设密码、不加密；数据不会自动同步。

已有数据库启动时会迁移到 schema v5。v5 增加长期成员档案、周期活动分类与学期关联、道具清单及库存流水表；升级前请在设置中导出备份。照片、视频、音频和文档与 SQLite 分开保存，换设备时请分别导入数据库和媒体包。设备间无线传输尚未实现。

## 页面操作

- **成员资料**：新建学期、管理名册与按学期保存的职位。点击成员行打开名片，查看长期资料、各学期记录和职位。
- **当前学期**：在成员页面选择目标学期并点“设为当前学期”。总览、日常训练和相关列表会按当前学期呈现。创建新学期后请检查当前学期选择。
- **成员 Excel 导入**：在成员页面下载 XLSX 模板，填写后选择导入。应用先预览有效行、匹配项及冲突；确认后再应用导入。遇到重复成员时按预览选择更新或跳过。
- **训练考勤**：按训练日期登记和确认出勤。
- **日常**：记录训练日期/时段、名册考勤和笔记，添加照片、视频、音频或 PDF/DOCX 训练附件。
- **活动相册**：为活动设置所属学期，并可选择周期活动类别。列表支持当前学期、历史学期、全部或未指定学期筛选；单次活动可自由填写名称。
- **档案馆**：维护长期成员档案，按学期及周期活动查看活动历史，并整理未归档活动。
- **道具**：维护道具名称、类别、数量与库存流水，可记录购入、领用、遗失等变动。
- **道具 Excel 导入**：下载道具模板并选择 XLSX 文件，先核对预览，再确认导入。模板格式错误会阻止导入，无效行会显示在预览中。
- **表演套路**：管理照片、视频、音频以及 PDF/DOCX 文档附件；点击文档可在应用内打开。
- **训练计划、通讯与总结、经费账本、历史资料库**：管理对应记录和附件。
- **设置**：分别导入/导出数据库及媒体包，并比较媒体清单。

模板作为 `native_app/assets/templates/` 应用资源随安装包提供；“下载模板”会将 XLSX 保存到用户选择的位置。模板生成器的中间输出保存在本地 `outputs/`，不会打入安装包或版本库。

## 文档预览

PDF 在应用内预览。DOCX 预览只提取纯文字，不保证保留字体、表格样式、图片或分页；旧 `.doc` 文件不支持正文预览。

## 从源码运行与构建

在 `native_app/` 目录使用 Flutter stable 3.47.5 或兼容版本。Windows 构建需要 Visual Studio Desktop development with C++；Android 构建需要 JDK 17 和 Android SDK。

```powershell
flutter pub get
flutter run -d windows
flutter build windows --release
flutter build apk --release
```

Windows 输出目录为 `build/windows/x64/runner/Release/`；APK 输出到 `build/app/outputs/flutter-apk/app-release.apk`。
