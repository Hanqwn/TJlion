# Lion Manager 原生应用使用说明

Lion Manager 使用 Flutter/Dart 构建为原生桌面和 Android 应用。Windows 版在自己的应用窗口运行；Android 版以 APK 安装。应用不通过浏览器或 WebView 打开。

## 安装

### Windows

下载并解压 `dist/native/windows.zip`，保留整个 `windows` 文件夹及其目录结构，然后运行 `dist/native/windows/lion_team_manager.exe`。不要只复制 EXE；旁边的 DLL、`data` 目录和 Flutter 运行库都是程序所需文件。

### Android

安装 `dist/native/android/lion_team_manager-release.apk`。此 APK 使用项目 debug key 签名，适合内部侧载；向 Play Store 发布前需要配置正式签名密钥。

本次发布只提供 Windows 和 Android 包。Linux、macOS、iOS 目录是项目源码，不代表这些平台已有安装包。

## 首次启动与数据库

安装包不包含预置成员数据或 `seed.sqlite3`。首次启动会用 `native_app/assets/schema.sql` 创建空的本机 SQLite 数据库。已有用户可在 **设置 → 导入数据库** 中选择要继续使用的数据库文件。数据库使用普通 SQLite 格式，不设密码，也不加密。

应用启动时会将旧本地数据库迁移到 schema v4。v4 增加训练日常附件关联及按学期保存的成员职位，同时保留原有记录和媒体路径。升级前请先在设置中导出数据库备份。

数据库与照片、视频、音频、PDF/DOCX 附件分别存储。换设备或重装前，请分别导出数据库和媒体包；导入后检查记录与附件清单是否匹配。数据库本身不会自动在设备间同步。

设备间无线传输目前尚未实现。请使用设置中的数据库与媒体包导入/导出，通过用户可访问的文件手动迁移。

## 页面操作

- **总览**：查看当前学期与主要功能入口。
- **成员资料**：管理当前学期名册。选择“新建学期”并输入名称后，新学期会自动选中，名册初始为空；可逐个添加成员或复制其他学期名册。职位随学期保存。
- **成员名片**：点选名册中的成员行打开名片，查看个人资料、各学期档案和对应职位。名片会按学号汇总学期记录；缺少学号时只显示所选成员记录。
- **训练考勤**：选择训练日期，登记、核对并确认出勤。
- **日常**：选择训练日期并记录训练时段、名册考勤和笔记；可以添加照片、视频、音频及 PDF/DOCX 附件，保存时会显示日期、出勤数量和附件数量供确认。
- **活动相册**：管理活动记录并关联媒体附件。
- **表演套路**：记录套路资料，可添加照片、视频、音频以及 PDF/DOCX 文档。点击文档附件可在应用内打开。
- **训练计划**：查看和管理训练安排。
- **通讯与总结**：整理通讯稿、会议总结及相关文档附件。
- **经费账本**：记录和查询经费收支。
- **历史资料库**：浏览附件和历史资料清单。
- **设置**：导入/导出数据库与媒体包，并比较设备间缺失的媒体附件。

## 文档预览

PDF 在应用内预览。DOCX 预览提取纯文字，不保证保留字体、排版、表格样式、图片或分页。文档导入器接受 PDF 和 DOCX；旧 `.doc` 文件不支持正文预览。

## 从源码运行与构建

在 `native_app/` 目录使用 Flutter stable 3.47.5 或兼容版本。Windows 构建需要 Visual Studio 的 Desktop development with C++ 工作负载；Android 构建需要 JDK 17 和 Android SDK。

```powershell
flutter pub get
flutter run -d windows
flutter build windows --release
flutter build apk --release
```

Windows 运行目录为 `build/windows/x64/runner/Release/`；APK 输出到 `build/app/outputs/flutter-apk/app-release.apk`。
